# Aden Reading

为 iPad、iPhone 和电脑制作的英语短文朗读应用。沿用背单词应用的深蓝绿、薄荷绿、暖黄色和白色卡片风格。

## 使用

进入页面后选择 No.，每个 No. 对应一份来源文档。一次显示一篇，使用 Previous / Next 切换，Menu 查看该文档全部短文。重新打开文档时继续上次打开的篇目。正文默认 26px，可调至 20–34px。

阅读页可见且没有手动暂停时自动计时。切换后台、进入目录或阅读记录时停止。跨午夜按设备本地日期分开记账；每天保存阅读的文档、篇目和每份文档的时长。记录使用独立键 `aden-reading-progress-v1` 保存在当前浏览器，支持导出 JSON 备份。不会改变背单词软件的学习记录。此版本统计前台阅读时间，不使用麦克风判断是否实际朗读。

添加到 iPad 主屏幕后，已打开过的文档可以离线阅读。首次访问需要联网。应用和记录均无账号同步。

## 当前材料

10 份材料，共 294 篇：No.1（33）、No.2（35）、No.3（16），No.4–10（各 30）。来源是用户提供的 No.1–5 PDF 和 No.6–10 Word 文档。

原文内容及中文词义提示保留。PDF 仅去掉页码、重接跨页句子、清理因换行产生的空格及中文部首兼容字形。没有标题的短文使用“短文 XX”。不自动改写原文中的语法或拼写。

## 扩展材料

内容与界面分离。无需修改程序：

1. 将新文档转换为 `data/no-11.json`（或下一编号），保持 `schemaVersion` 为 1。
2. 文件结构与现有文档一致：文档 `id`、`number`、`label`、`sourceFile`、`passages`。每篇包含稳定 `id`、`title`、`paragraphs` 数组。
3. 在 `data/catalog.json` 的 `documents` 数组追加一条元数据，指定篇数和相对文件路径。
4. 已有文档和篇目 ID 不要更改，新增篇目使用新 ID，以保留阅读记录。

原始 PDF/Word 不需要上传到公开仓库。新材料需先完成文本提取和短文拆分，再添加 JSON；应用不在浏览器内解析 Word/PDF。

所有资源都使用相对路径。独立 service worker 的作用范围为 Reading/，缓存仅清理 `aden-reading-` 开头的旧版本。
