# 词光（Word Spark）

一个适合初中生在 iPad、iPhone 和电脑上使用的英语背单词 Web App。

## 功能

- 277 个教材单词和短语，按 Unit 1–6 分组，词库与程序完全分离
- 进入页面先选择一个或多个 Unit；支持全选和中途更换单元
- 学习任务、测验、拼写及错词复习均限定在所选单元内
- 单词卡片、英文语音朗读、例句和中文释义
- 优先选择英式英语语音，可切换设备提供的英语声音并试听；实际音色取决于设备
- 短语拼写自动显示空格和标点，支持连字符、缩写和两个字母的词
- “认一认”提供英译中、中文选英文双向选择
- “拼一拼”根据中文和字母提示，逐格填写缺少的字母，并即时反馈正确拼写
- “学习任务”展示新单词时自动朗读，错词可一键加入专项复习
- 错词在“认一认”和“拼一拼”中都重新答对后自动移出复习列表
- 自动记录已学、掌握、错词、今日进度和连续学习天数
- 学习记录保存在浏览器本地，更新代码或词库不会清除
- 支持添加到 iPad/iPhone 主屏幕并离线使用

## 更新词库

只需修改 `data/words.json`。每个单词保持 `id` 唯一且长期不变，已有学习记录就会继续对应原来的单词。

## 本地预览

本项目是纯静态网站，需要通过 HTTP 服务打开（不能直接双击 `index.html`，否则浏览器无法读取 JSON 词库）。例如：

```bash
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 部署

项目可直接部署到 GitHub Pages。所有资源使用相对路径，因此仓库项目页和自定义域名均可正常工作。
